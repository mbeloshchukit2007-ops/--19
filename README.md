# Практична робота: Калькулятор середньої оцінки студента

## Контрольні запитання:

### 1. Що таке JavaScript та для чого використовується ця мова програмування?
**Відповідь:** JavaScript — це мова програмування, яка в першу чергу застосовується для створення інтерактивних та динамічних вебсайтів (анімації, обробка кліків, робота з формами). Завдяки середовищу Node.js мова також використовується для серверного програмування, створення API та додатків.

### 2. Які основні відмінності між JavaScript та Java?
**Відповідь:**
- **Типізація:** JavaScript використовує динамічну типізацію, а Java — строгу статичну.
- **Виконання:** JS виконується у браузері або через Node.js без попередньої компіляції, тоді як Java компілюється в байт-код і працює у JVM.
- **Модель ООП:** JS побудований на прототипному наслідуванні, Java — на класичній системі класів.

### 3. Яку роль відіграє JavaScript у клієнтській частині вебзастосунків?
**Відповідь:** У клієнтській частині JS відповідає за логіку взаємодії з користувачем: змінює DOM-структуру сторінки без перезавантаження, обробляє події (кліки, введення тексту), валідує форми та робить асинхронні запити на сервер (Fetch/AJAX).

### 4. Які типи даних підтримує JavaScript?
**Відповідь:**
- **Примітивні:** number, string, boolean, null, undefined, bigint, symbol.
- **Складні:** object (об'єкти, масиви Array, функції Function).

### 5. Чим відрізняються способи оголошення змінних let, const та var?
**Відповідь:**
- `var` — застаріле ключове слово з функціональною областю видимості.
- `let` — оголошення змінної з блоковою областю видимості (`{}`), яку можна змінювати.
- `const` — оголошення константи з блоковою областю видимості, значення якої не можна перезаписати після присвоєння.

## Висновок:
У ході практичної роботи було реалізовано алгоритм на JavaScript для розрахунку середнього арифметичного балу студента за переданим масивом оцінок. Додано перевірку правильності вхідних даних (валідацію числових типів та діапазону від 0 до 100). Також опрацьовано теоретичні контрольні запитання щодо синтаксису мови, її типів даних та принципів роботи у вебі.
